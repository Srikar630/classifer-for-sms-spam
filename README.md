📩 Spam SMS Classifier
A machine learning web app that classifies SMS messages as Spam or Not Spam using TF-IDF features and a Multinomial Naive Bayes model, with a Streamlit UI.

Problem Statement
Spam messages waste time and can be used for phishing. This project detects spam SMS automatically from the message text.

Tech Stack
Python, scikit-learn, pandas, joblib, Streamlit

Dataset
SMS Spam Collection (Kaggle). Download spam.csv and place it in the project root.

Project Structure
spam-sms-classifier/
├── app.py            # Streamlit UI
├── train.py          # Model training script
├── requirements.txt
├── spam.csv          # (download from Kaggle)
└── spam_model.pkl    # (generated by train.py)
How to Run
pip install -r requirements.txt
python train.py
streamlit run app.py
Results
Accuracy: ~97-98% on the test set (update with your actual numbers after running train.py).
